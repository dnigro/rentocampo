# Landing Page - RentoCampo

Landing profesional para captar propietarios rurales que quieren publicar sus campos.

## 📋 Descripción

- **Objetivo:** Generar leads de propietarios rurales
- **Formulario:** Referencia visual; la aplicación gestiona consultas mediante Supabase
- **Diseño:** Responsive (mobile, tablet, desktop)
- **Stack:** HTML/CSS/JavaScript puro

## 📁 Archivos

- `index.html` - Estructura HTML (9 secciones)
- `styles.css` - Estilos CSS responsive
- `main.js` - Formulario + eventos
- `README.md` - Este archivo

## 📱 Secciones

1. **Header** - Navbar sticky con logo y navegación
2. **Hero** - Propuesta de valor principal
3. **Confianza** - 3 beneficios clave
4. **Publicar** - Formulario Lead
5. **Cómo funciona** - 3 pasos del proceso
6. **Visibilidad** - Mock de mapa
7. **FAQ** - Preguntas frecuentes
8. **CTA Final** - Último llamado a acción
9. **Footer** - Links y copyright
