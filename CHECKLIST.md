# RentoCampo - Checklist de Desarrollo

Usá esta plantilla al iniciar cada sesión de trabajo.

---

## ✅ Checklist de inicio de sesión

- [ ] `git pull origin main` — Traer últimos cambios
- [ ] Live Server corriendo en `http://127.0.0.1:5500`
- [ ] Abrir landing en el browser para verificar

---

## 🔧 Durante el trabajo

- [ ] Guardá frecuentemente (auto-format con Prettier activo)
- [ ] Verificá cambios en Live Server (hot reload automático)
- [ ] Commits atómicos: un commit por cambio lógico

### Formato de commits

```
feat: nueva funcionalidad
fix: corrección de bug
style: cambio de estilos
content: actualización de contenido
chore: mantenimiento
```

---

## 🚀 Al terminar la sesión

- [ ] `git status` — Verificar archivos modificados
- [ ] `git add .` — Agregar todos los cambios
- [ ] `git commit -m "tipo: descripción clara"` — Commit
- [ ] `git push origin main` — Push a producción
- [ ] Verificar deploy en https://rentocampo.vercel.app (~30 seg)
